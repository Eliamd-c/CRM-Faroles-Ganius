# UI Basada en Formularios Simples

## Visión general
Al editar el flujo de "saludo a nuevos seguidores", el video destaca: *"acá el menú es bastante amigable, a diferencia del resto de automatizaciones... nos pregunta básicamente todo mediante texto. Es como, 'Okay, vamos a editar esto'."*

## Oportunidad de Mejora para nuestro CRM
El Flow Builder (lienzo de nodos) es ultra-flexible pero puede ser intimidante para tareas extremadamente comunes (como cambiar el saludo inicial o capturar un correo). 

## Posible Implementación
- Crear "Plantillas Rápidas" en el CRM.
- En lugar de abrir el gran lienzo de Drawflow, ofrecer una pantalla con un simple formulario tipo Typeform: "Mensaje 1:", "Botón:", "Mensaje final:".
- Por debajo, el sistema traduce este formulario a nuestro formato `flows.json`, pero la experiencia para el usuario que solo quiere hacer un cambio rápido es infinitamente más amigable que cablear nodos.
